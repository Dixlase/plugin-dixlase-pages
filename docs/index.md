# DixlasePages プラグイン

## 概要

**DixlasePages** は、Dixlase の静的ページ（会社概要、料金表、規約、ランディング等）を管理する公式プラグインです。管理画面から WYSIWYG ライクなエディタで作成・編集し、公開・下書き・非公開を切り替えられます。

## 主な特徴

- **エディタタイプの選択**: 用途に応じて複数のエディタを切り替え（シンプル / 詳細モード）
- **保存方式の選択**: データベース保存 / ファイル保存の切り替え（サイト規模やバックアップ方針に応じて）
- **リビジョン管理**: 各ページの編集履歴を自動保存。過去バージョンとの比較・復元が可能
- **プレビュー**: 公開前に、実際のフロント表示と同じレイアウトで確認可能
- **ルートスラッグ管理**: `/page/{slug}` の `{slug}` 部分をページごとに指定
- **公開権限のロール制御**: どのロール以上のメンバーが公開操作をできるかを指定
- **ゴミ箱**: 削除は 2 段階（一旦ゴミ箱 → 完全削除）、誤削除からの復元が容易

## いつ使うか

- 会社概要、利用規約、プライバシーポリシー等の**固定ページ**を作りたい
- ブログとは別に、**ランディングページ**や**キャンペーン告知**を作りたい
- 複数人で編集し、**リビジョン管理**で誰がいつ何を変更したかを追跡したい

## いつ不要か

- 時系列で並ぶ**記事型コンテンツ**（Blog 用途にはブログ機能を利用）
- ページ数が極端に少なく、テーマ内の Blade テンプレートで直接管理するほうが早い場合

## ページの状態

| 状態 | 説明 | フロントでの見え方 |
| --- | --- | --- |
| **公開** | 一般訪問者に閲覧可能 | `/page/{slug}` でアクセス可 |
| **下書き** | 編集中。フロントには出ない | 404、または管理ログイン中はプレビュー可能 |
| **非公開** | 意図的に非表示 | 404 |
| **ゴミ箱** | 削除操作後、完全削除まで一時保管 | 復元可能。完全削除で消滅 |

## 他プラグイン・機能との関係

- **DixlaseMenus**: メニューの項目として作成したページをリンクできる
- **DixlaseSEO**: 各ページに固有のメタタグ / OGP を設定可能（SEO プラグイン導入時）
- **DixlaseMultilingual**: 多言語対応時、ページごとに言語別バージョンを持てる

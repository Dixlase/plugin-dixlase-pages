# DixlasePages 管理画面での使い方

## アクセス方法

管理画面 → **ページ管理**

## ページ一覧画面

### 主な操作

- **検索**: ページタイトル・スラッグで絞り込み
- **ステータスフィルタ**: 公開 / 下書き / 非公開の切り替え
- **一覧の操作**: 各行から「編集」「プレビュー」「削除（ゴミ箱へ）」
- **新規作成**: 画面上部の「新規ページ」ボタン
- **ゴミ箱**: 削除したページの復元・完全削除

## 新規ページの作成

### 1. 「新規ページ」ボタンをクリック

作成フォームが開きます。

### 2. 基本情報を入力

| 項目 | 内容 | 必須 |
| --- | --- | --- |
| **タイトル** | ブラウザタブ・見出し・SEO title に使われる | ✓ |
| **スラッグ** | URL パス。`/page/{slug}` の `{slug}` 部分。半角英数字とハイフン推奨 | ✓ |
| **ステータス** | 公開 / 下書き / 非公開 のいずれか | ✓ |
| **本文** | 選択したエディタタイプでコンテンツを入力 | ✓ |

### 3. エディタタイプの選択

サイトの設定と個々のページ設定により、以下のエディタが選択できます：

| エディタ | 用途 |
| --- | --- |
| **シンプルエディタ** | 見出し / 段落 / リスト / リンク等の基本要素のみ。編集者向けの UX が優しい |
| **詳細エディタ** | ブロック追加・カスタム HTML・Blade テンプレート等をフル活用できる。開発者向け |

デフォルトは「設定」画面で指定でき、個別ページごとに切り替えも可能です。

### 4. 保存方式の選択

各ページの本文は、以下のいずれかの方法で保存されます：

| 方式 | メリット | デメリット |
| --- | --- | --- |
| **データベース保存** | 検索が高速。バックアップは DB dump に含まれる | サイズが大きくなると DB 肥大化 |
| **ファイル保存** | 大容量の HTML でも DB を圧迫しない。Git 管理も可能 | ファイル権限管理が必要 |

判断がつかなければ、初期は「データベース保存」推奨。

### 5. プレビュー

「プレビュー」ボタンで **公開前に表示を確認** できます。実際のフロントテーマで描画され、レイアウト崩れをチェックできます。

### 6. 保存

- **下書き保存**: そのまま「保存」で下書き状態のまま
- **公開**: ステータスを「公開」に切り替えて保存 → `/page/{slug}` で公開されます

## 既存ページの編集

1. 一覧から対象ページの「編集」をクリック
2. 内容を編集
3. 「保存」で **リビジョンが自動的に作成** されます

編集時、公開ページのステータスを「非公開」や「下書き」に戻すことも可能です。

## リビジョン管理

各ページの右上「リビジョン」から編集履歴を確認できます。

### 一覧画面

- 各リビジョンに **編集者・編集日時・変更概要** が表示されます
- 「表示」で個別のバージョン内容を確認可能
- 「復元」で任意のバージョンに戻せます（現バージョンは新しいリビジョンとして保存されるので、元にも戻せます）

## ページ設定（Pages プラグイン全体の既定値）

管理画面 → ページ管理 → **設定**

| 項目 | 説明 |
| --- | --- |
| **ルートスラッグ** | `/page/xxx` の `page` 部分。他プラグインと衝突する場合など変更可 |
| **デフォルトステータス** | 新規作成時の初期ステータス |
| **デフォルトエディタタイプ** | 新規作成時に選択されているエディタ |
| **デフォルト保存方式** | 新規作成時の既定保存先 |
| **公開権限（min_role）** | ページを「公開」操作できる最低ロール（例: `editor` 以上） |

> **簡単モード**: 表示中に「簡単モード」トグルがある場合、一部の設定が自動的に構成されます。すべての設定をカスタマイズするには「詳細モード」に切り替えてください。

## ゴミ箱の運用

- 一覧から「削除」を実行するとまず **ゴミ箱に移動**（フロントからは 404）
- ゴミ箱画面から：
  - **復元**: 元のステータスで一覧に戻す
  - **完全削除**: DB からも削除（ファイル保存の場合はファイルも削除）
  - **すべて空に**: ゴミ箱を一括で完全削除

## トラブルシューティング

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| ページが公開されているのに 404 | スラッグに全角文字・空白が含まれている | 半角英数字とハイフンで再入力 |
| 公開ボタンが押せない | 公開権限（min_role）が現在のメンバーロールより高く設定されている | 設定画面で公開権限を調整、またはロールを上げる |
| プレビューが白紙 | テーマの Blade でページ描画に失敗している | フロントテーマ側のログ確認 |
| リビジョンが増えすぎている | 自動保存の頻度が高い可能性 | 古いリビジョンの一括整理は別途検討（core にコマンドあり） |

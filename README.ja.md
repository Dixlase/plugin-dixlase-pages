# Dixlase Pages

For English, see [README.md](./README.md).

Dixlase 用の固定ページ管理プラグイン。

- 設定可能な URL プレフィックス配下に階層的なページツリー
- GUI / Markdown / HTML の 3 種類のエディタ、データベース またはファイルでの保存
- ページごとのカスタム CSS / JavaScript
- 復元可能なリビジョン履歴
- 下書き / 公開 / 予約公開のステータス
- DixlaseSEO 連携による SEO メタ管理
- DixlaseMenu からの内部リンク参照に対応

## 機能

- **階層ページ**
  深度 3 階層まで (`/page/a/b/c`)。編集フォームで親ページを選択できます。親を削除しても子ページは cascade 削除されず、トップレベルへ昇格します。スラッグの一意性は親ごとに評価されます。
- **3 種類のエディタ**
  GUI ビルダー、Markdown、HTML。簡単モード(管理画面の既定)では新規ページを GUI / Markdown のみに制限します。詳細モードに切り替えると HTML も解放されます。既存ページは作成時のエディタ種別で編集を続行します。
- **2 種類のストレージ**
  作成時に選択:
    - **データベース** — コンテンツをページ行に保存します。短いページに最速の選択肢です。
    - **ファイル** — コンテンツを ファイルに書き出します。長文ページや、テキストエディタ・Git で扱うコンテンツに向いています。
- **ページごとのカスタム CSS / JS**
  各ページは独自のスタイルシートとスクリプトを持てます。キャッシュヘッダおよび CSP 例外は自動で処理します。
- **リビジョン**
  保存のたびにスナップショットを記録します。手動・自動のリビジョンは管理画面で一覧でき、現在の状態を上書きせずに復元できます(復元前バックアップを自動作成)。
- **公開ワークフロー**
  下書き / 公開 / 予約公開 (将来日時の `published_at`) を選択できます。下書きおよび予約中のページはログイン中の管理者にはプレビューバナー付きで表示され、公開ユーザーには 404 を返します。
- **SEO メタ**
  `dixlase-seo` プラグインが有効なときは、編集フォームに meta-description と OGP 画像のフィールドが現れます。値の保存は Dixlase SEO 側が `seo-meta` capability 経由で担当します。
- **URL プレフィックスの設定**
  ルートプレフィックス(既定 `page`)は管理画面の設定に保存され、公開ルートおよび管理画面の URL プレビュー双方が参照します。
- **ロール権限**
  Pages の管理メニューに対する既定権限は `config/admin/roles.php` で宣言し(一覧 / 新規: エディタ以上、設定: 管理者のみ)、コアの `PermissionRegistry` が実行時に解決します。
- **内部リンクプロバイダ**
  `RouteSlugProvider` と Linkable プロバイダを実装しているので、他プラグイン(メニュー、ブログ等)がページを ID 参照しただけで `/page/parent/child` 形式の正しい URL を組み立てられます。locale プレフィックス配下も自動対応します。

## インストール

1. プラグインを Dixlase インストール先の `plugins/DixlasePages` に配置します。
2. 管理画面の **ダッシュボード → プラグイン** から有効化するか、お使いの環境の CLI インストールコマンドを実行します。
3. 有効化すると、本プラグインのマイグレーションが自動実行され、既定の URL プレフィックス (`page`)、公開可能ロール、ページステータスの選択肢が seed されます。

## 使い方

有効化すると、管理画面のサイドバーに **ページ管理** が表示されます。

- **一覧画面**:
  全ページを検索 / ステータスフィルタ / 列単位ソートで閲覧できます。
- **新規ページ**:
  エディタを分割ビューで開きます — 左にコンテンツエリア、右に設定(ストレージ種別、スラッグ、親ページ、言語、ステータス、カスタム CSS / JS、SEO メタが有効ならその入力欄)。
- **編集**:
  既存ページに対して同じエディタを開きます。HTML / Markdown / GUI エディタはライブプレビュー対応です。
- **設定** (管理者のみ):
  URL プレフィックス、既定のエディタ種別、公開可能な最小ロールを変更できます。

公開 URL はプレフィックスとページのパスセグメントから構成されます。`about` という名前のトップレベルページは `/page/about`、その下の子ページ `team` は `/page/about/team` になります。

## Capabilities

本プラグインは `plugin.json` で以下の capability を宣言しており、他プラグインとの連携が可能です。

- **`seo-meta`**
  — DixlaseSEO プラグインから、各ページに対する SEO メタデータ(meta description / OGP 画像など)を読み書きできる契約。Pages 編集フォームの SEO セクションは、DixlaseSEO が有効なときにこの capability 経由で連動します。
- **`linkable`**
  — DixlaseMenu などの内部リンクを扱うプラグインから、本プラグインのページを ID 指定で参照できる契約。階層パス込みの公開 URL は自動で組み立てられ、locale プレフィックス配下も追従します。
